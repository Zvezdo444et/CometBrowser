# CometBrowser

CometBrowser — это легкий и современный веб-браузер, написанный на Java. Проект ориентирован на удобное управление сессиями, профилями и современный пользовательский интерфейс.

## Основные особенности
- **Управление профилями:** Создание и хранение независимых профилей пользователей.
- **Работа с сессиями:** Автоматическое сохранение и восстановление вкладок.
- **Современный движок:** Использование WebView2 для быстрой и качественной отрисовки веб-контента.
- **Кастомизация:** Поддержка тем оформления и удобная навигация.

## Технологии
- **Язык:** Java
- **Рендеринг:** WebView2
- **Сборка:** Maven

## Установка и запуск
1. Убедитесь, что у вас установлена Java (JDK 17+).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Zvezdo444et/CometBrowser
3. Перейдите в папку проекта и выполните сборку:
    ```bash
   mvn clean package
4. Запустите собранный jar-файл:
    ```bash
   java -jar target/CometBrowser-1.0.jar
